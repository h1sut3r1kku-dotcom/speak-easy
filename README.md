## ℹ️ Общее описание
Приложение **speak-easy** предназначено для удобного управления словарным запасом. Вы можете:
*   Добавлять новые слова с переводом и примерами.
*   Просматривать полный список записей.
*   Редактировать или удалять ненужные записи.
*   Мгновенно искать слова по базе.

Интерфейс интуитивно понятен и состоит из трёх основных экранов: **Главный список**, **Форма добавления/редактирования** и **Карточка слова**.

---

## Функционал

### 1. Главный экран
Центральный хаб приложения.
*   **Поиск:** Строка поиска фильтрует список в реальном времени (по слову, переводу или примеру).
*   **Список слов:** Отображает пары "Слово — Перевод".
*   **Добавление:** Кнопка `+` открывает форму создания новой записи.
*   **Пустое состояние:** Если слов нет, приложение предложит добавить первую запись.

### 2. Экран добавления / редактирования
Здесь вы создаете или изменяете карточку слова.
*   **Поля ввода:**
    *   Слово (английский вариант)
    *   Перевод (русский вариант)
    *   Пример использования
    *   Категория (тема слова)
*   **Действия:** Сохранение изменений или отмена.

### 3. Карточка слова
Подробный просмотр конкретной записи.
*   Отображение всех деталей (слово, перевод, пример).
*   Возможность быстрого перехода в режим редактирования.
*   Кнопка удаления записи.

## Руководство пользователя

### Как найти слово?
На главном экране нажмите на строку поиска. Вводите текст — список отфильтруется автоматически. Поиск работает по всем полям (не чувствителен к регистру).
> *Пример: ввод "app" найдет слова "apple", "application" или слова, где в примере есть "app".*

### Как добавить новое слово?
1. На главном экране нажмите оранжевую кнопку **«+»**.
2. Заполните поля: Слово, Перевод, Пример, Категория.
3. Нажмите **«Сохранить»**.

### Как изменить или удалить слово?
1. Нажмите на нужное слово в списке, чтобы открыть **Карточку слова**.
2. Нажмите на поле, которое хотите изменить, или выберите действие «Редактировать».
3. Внесите правки и нажмите **«Сохранить»**.
4. Чтобы удалить запись, нажмите серую кнопку **«Удалить»** в карточке слова.
> ⚠️ **Внимание:** Удаление необратимо! Подтверждение не требуется.

## Технические детали

*   **Язык разработки:** Java
*   **База данных:** Room (SQLite) — локальное хранение.
*   **Архитектура:** Асинхронная работа с БД (в отдельном потоке) для предотвращения зависания интерфейса.
*   **Ограничения:**
    *   Работает полностью офлайн.
    *   Рекомендуемый лимит записей для максимальной производительности: до 1000.
    *   Категории чувствительны к регистру ("Еда" и "еда" — разные категории).
